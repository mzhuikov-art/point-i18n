## [1.2.3] - 30.09.2026

### Added
- Настройка `i18nRemote.projectsApiBaseUrl` и команда `Point I18n: Configure Projects API Base URL`
  - Список проектов запрашивается с `{projectsApiBaseUrl}/api/v1/localization-project`
  - При первом запросе, если URL не задан, открывается диалог настройки
- Опциональный язык `cn`
  - Выбор языка, статистика, поиск, создание и редактирование ключа, hover
  - Поле китайского перевода необязательное
  - Если локаль `cn` недоступна, остальные языки загружаются как раньше
  - Автоперевод на китайский через DeepL (`ZH`)

### Changed
- Запрос списка проектов больше не идёт через proxy `apiBaseUrl`

## [1.2.2] - 21.11.2025

### Added
- Добавлен функционал автоматического перевода ключей через DeepL API
  - Кнопка перевода 🌐 в формах создания и редактирования ключей (VSCode и WebStorm)
  - Автоматическое заполнение переводов на английский и узбекский языки при вводе русского текста
  - Поддержка бета-языков DeepL (узбекский язык)
  - Настройка DeepL API ключа через команду `Point I18n: Configure DeepL API Key`
  - Настройка DeepL API ключа через настройки: `i18nRemote.deepLApiKey`

### Changed
- Улучшена обработка ошибок создания ключей в WebStorm версии
- Добавлена валидация ответов API при создании и обновлении ключей

## [1.1.1] - 07.11.2025

### Added
- Настройка базовых URL через конфигурацию расширения
  - `i18nRemote.apiBaseUrl` - базовый URL для API (auth, projects, create, update, search)
  - `i18nRemote.localizationApiBaseUrl` - базовый URL для API локализации (fetch locales)
- Команды для настройки URL:
  - `Point I18n: Configure API Base URL` - настройка базового URL для API
  - `Point I18n: Configure Localization API Base URL` - настройка базового URL для API локализации
- Автоматическое открытие диалога настройки при отсутствии URL с кнопкой "Настроить"

### Changed
- Улучшена обработка ошибок авторизации: теперь выводится полное описание ошибки из API (`error_description`)
- Нормализация URL: автоматическое удаление завершающего слэша (работают оба варианта: `https://example.com` и `https://example.com/`)
- Упрощены HTTP заголовки в запросах API (удалены избыточные заголовки браузера)

### Fixed
- Исправлена обработка ошибок авторизации с выводом детального описания проблемы

## [1.1.0] - 07.11.2025

### Added
- Поиск по переведенному тексту в сайдбаре
  - Поиск файлов по переведенному тексту, даже если в коде используется только ключ i18n
  - Настройка пути поиска (по умолчанию `src`)
  - Автоматическое сохранение последнего пути поиска (`i18nRemote.searchPath`)
  - Отображение результатов с файлом, строкой, ключом и переводом
  - Клик по результату открывает файл на нужной строке
  - Параллельная обработка файлов для ускорения поиска
  - Умная фильтрация исключает ненужные директории (node_modules, dist, build и т.д.)

### Changed
- Оптимизирован поиск по переводам для работы с большими проектами
- Увеличен лимит обрабатываемых файлов с 1000 до 5000
- Улучшена производительность поиска за счет батчевой обработки файлов (по 20 файлов параллельно)
- Использование `readFile` вместо `openTextDocument` для ускорения чтения файлов

## [1.0.0] - 07.11.2025

### Added
- Inline-переводы: отображение переводов прямо в коде вместо ключей
- Hover с информацией: просмотр ключа и перевода при наведении курсора
- Быстрое редактирование: клик на перевод для просмотра оригинального ключа
- Синхронизация с сервером: загрузка актуальных переводов из API
- Работа с проектами: выбор проекта и переключение между проектами локализации
- Управление ключами через sidebar:
  - Поиск ключей локализации по названию
  - Создание новых ключей с переводами
  - Редактирование существующих ключей
- Sidebar панель "Управление" в Activity Bar
- Настройки:
  - Язык для отображения переводов (`i18nRemote.locale`)
  - Ключ проекта (`i18nRemote.projectKey`)
- Команды:
  - `Point I18n: Quick Login` - Авторизация и загрузка локалей
  - `Point I18n: Fetch locales now` - Обновить переводы с сервера
  - `Point I18n: Toggle inline translations` - Вкл/выкл inline-переводы
- Горячие клавиши:
  - `Cmd+Shift+I` (macOS) - Включить/выключить inline-переводы
